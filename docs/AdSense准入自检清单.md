# AdSense 准入自检清单与上线前核对表

本清单用于提交 Google AdSense 申请前的人工复核，以及上线后每月的例行检查。
打勾项均可在站点上直接验证。

---

| # | 检查项 | 判定标准 | 状态 |

| 2 | 已启用 HTTPS | 浏览器地址栏显示锁标志，无「不安全」警告 | ☐ |

## 四、SEO 基础

- [ ] `sitemap.xml` 存在，且收录首页、全部协议页、代码示例页与静态页面
- [ ] `robots.txt` 存在，且声明了 `Sitemap: https://www.removewatermarker.com/sitemap.xml`
- [ ] 每个页面有唯一的 `title` 与 `description`
- [ ] 每页有 `<link rel="canonical">`，指向自身规范地址
- [ ] 每页有 Open Graph 标签（`og:title` / `og:description` / `og:url` / `og:type`）
- [ ] URL 统一小写、统一带尾斜杠（`next.config.ts` 中 `trailingSlash: true`）
- [ ] 结构化数据（JSON-LD）可被 Google 富媒体测试工具验证
- [ ] 图片均有 `alt` 文本
- [ ] 已在 Google Search Console 提交 sitemap 并完成域名所有权验证

## 五、广告相关合规

- [ ] 广告容器带「广告」文字标识（`AdSlot` 组件已内置 `ad-slot__label`）
- [ ] 广告与正文内容有明确视觉区分，不混排
- [ ] 不在代码块、表格中间插入广告
- [ ] 不使用遮挡内容的浮层或自动跳转
- [ ] 已部署 Google 官方 Funding Choices / Privacy & Messaging 中心
- [ ] 已接入 GA4 并在 AdSense 后台完成关联
- [ ] Cookie 同意横幅在用户做出选择前不加载 AdSense 脚本
- [ ] 用户选择「仅必要」后不请求个性化广告（`google_adsense_rr=on`）
- [ ] 广告声明页已说明广告商责任边界
- [ ] 未使用「点击这里」「更多产品」等诱导性锚文本

### 友情链接区块专项

- [ ] 页脚链接数 ≤ 8（当前正好 8 个，已达上限）
- [ ] 全部为文字链接，无关键字堆砌
- [ ] 锚文本为真实品牌/工具名称
- [ ] 全部外链带 `rel="nofollow noopener"` 且 `target="_blank"`
- [ ] 区块位于页脚底部，与正文有视觉分隔
- [ ] 具备一键隐藏能力（若被判定为低价值链接区）

## 七、提交申请

1. 登录 [Google AdSense](https://adsense.google.com)
2. 「添加网站」→ 输入 `www.removewatermarker.com`
3. 选择「通过 AdSense 展示广告」；如同时使用 Analytics，选择关联的 Analytics 账号
4. 按提示配置广告代码：站点已通过 `NEXT_PUBLIC_ADSENSE_CLIENT` 环境变量自动注入，
   无需手动改代码
5. 在「隐私与消息」中心配置 Cookie 提示与用户数据说明
6. 提交申请，等待审核（通常 1–3 周）

**审核期间注意**：不要频繁改版、域名不要迁移、不要批量新增低质页面、不要重复提交申请。

## 八、审核通过后的运营检查（每月）

- [ ] 「广告收入」与「页面状态」报表无异常
- [ ] 「政策违规」与「广告投放不足」通知已处理
- [ ] 站点新增若干型号协议页与示例代码（建议每月 1–2 篇）
- [ ] 关键页面（首页、协议页、代码页）的收录量未异常下降
- [ ] 证书未过期（Let's Encrypt 90 天有效期）
- [ ] 部署流水线运行正常，无构建失败

## 九、故障应急

| 场景 | 处置 |
| --- | --- |
| 收到「低价值内容」通知 | 立即补充协议页正文深度，增加型号、字段表与代码示例 |
| 收到「版权投诉」 | 核实来源，替换为自制内容或补充引用出处 |
| 收到「无效流量」警告 | 检查是否购买了流量或存在异常爬虫 |
| 收到「政策违规：误导性内容」 | 检查医疗相关表述，避免构成诊疗建议 |
| 友情链接被要求移除 | 临时在 `site.ts` 中清空 `friendLinks` 数组，重新部署 |
