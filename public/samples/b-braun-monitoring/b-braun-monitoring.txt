# B. Braun 生命体征监测设备通讯协议

- 协议标识：b-braun-monitoring
- 品牌：B. Braun（贝朗）
- 覆盖型号：B. Braun Monitoring Module、B. Braun VitalSigns Hub、B. Braun Space 监护模块
- 接口：RS-232 / RS-485 / 以太网
- 通讯参数：9600 / 19200, 8N1
- 报文长度：26 字节
- 最后更新：2026-07-08

## 说明

B. Braun 系列的监测模块通过串口上报生命体征，采用定长文本记录与关键字分组的混合结构，参数以「关键字:数值」形式成对出现，便于逐项核对。

## 字节流

45 43 47 52 3A 37 32 0D 53 50 4F 32 3A 39 38 0D
54 45 4D 50 3A 33 36 2E 38 0D

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `45 43 47 52` | 关键字 ECGR，对应 ECG 心率记录。 |
| `3A` | 冒号分隔符。 |
| `37 32` | 数值 72，表示心率 72 bpm。 |
| `0D` | 回车，本行结束。 |
| `53 50 4F 32` | 关键字 SPO2，对应血氧饱和度记录。 |
| `3A` | 冒号分隔符。 |
| `39 38` | 数值 98，表示血氧 98 %。 |
| `0D` | 回车，本行结束。 |
| `54 45 4D 50` | 关键字 TEMP，对应体温记录。 |
| `3A` | 冒号分隔符。 |
| `33 36 2E 38` | 数值 36.8，对应体温 36.8 °C。 |
| `0D` | 回车，记录结束。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat b-braun-monitoring.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd b-braun-monitoring.bin
```
