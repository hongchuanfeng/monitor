# Biolight iPM 系列监护仪通讯协议

- 协议标识：biolight-monitor
- 品牌：Biolight（普门科技）
- 覆盖型号：iPM8、iPM10、iPM12
- 接口：RS-232 / 以太网
- 通讯参数：115200, 8N1
- 报文长度：13 字节
- 最后更新：2026-07-30

## 说明

普门 iPM 系列使用双字节帧头 0xBDBD，随后是消息类型、长度、设备标识与参数块，末尾为 CRC16。设备标识字段使同一总线上区分多台监护机成为可能。

## 字节流

BD BD 01 00 06 00 01 00 01 02 48 C9 78

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `BD BD` | 帧头 0xBD 0xBD。 |
| `01` | 消息类型 0x01，实时数据推送。 |
| `00 06` | 负载长度 6 字节，含设备标识与参数块。 |
| `00 01` | 设备标识 0x0001。 |
| `00 01` | 参数编号 0x0001，对应心率测量项。 |
| `02 48` | 参数原始值 0x0248，按比例因子 0.1 换算为 58.4 bpm。 |
| `C9 78` | CRC16 校验值，小端序。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat biolight-monitor.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd biolight-monitor.bin
```
