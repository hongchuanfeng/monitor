# Biolight 普门呼吸机通讯协议

- 协议标识：biolight-ventilator
- 品牌：Biolight（普门科技）
- 覆盖型号：VG-8、VG-12、V8 呼吸机
- 接口：RS-232 / 以太网
- 通讯参数：115200, 8N1
- 报文长度：13 字节
- 最后更新：2026-07-18

## 说明

普门呼吸机沿用其监护与麻醉产品统一的 0xBDBD 帧头与 CRC16 校验方案，命令码区分握手、参数订阅、波形订阅与报警读取，一套编解码可横跨多条产品线。

## 字节流

BD BD 01 00 06 00 02 00 02 01 2C 3A B6

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `BD BD` | 帧头 0xBD 0xBD。 |
| `01` | 消息类型 0x01，实时数据推送。 |
| `00 06` | 负载长度 6 字节。 |
| `00 02` | 设备标识 0x0002。 |
| `00 02` | 参数编号 0x0002，对应分钟通气量 MV。 |
| `01 2C` | 参数原始值 0x012C，按比例因子 0.1 换算为 30.0 L/min。 |
| `3A B6` | CRC16 校验值，小端序。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat biolight-ventilator.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd biolight-ventilator.bin
```
