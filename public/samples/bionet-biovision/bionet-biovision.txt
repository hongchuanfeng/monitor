# Bionet BioVision 监护仪通讯协议

- 协议标识：bionet-biovision
- 品牌：Bionet
- 覆盖型号：BioVision、BioVision 2、iXensor、Carbon 18
- 接口：RS-232
- 通讯参数：115200, 8N1
- 报文长度：11 字节
- 最后更新：2026-08-22

## 说明

BioVision 系列采用紧凑的二进制帧结构：帧头、长度、通道号、数据区与校验字节依次排列。结构简单直观，适合作为中小型监护仪数据接入的参考实现。

## 字节流

55 AA 07 05 00 00 00 64 01 00 71

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `55 AA` | 帧头 0x55 0xAA。 |
| `07` | 数据区长度 7 字节，计数到校验字节之前。 |
| `05` | 通道号 5。 |
| `00 00` | 参数编号 0x0000，对应心率测量项。 |
| `00 64` | 参数值 0x0064，即 100 bpm。 |
| `01` | 状态标志 0x01。 |
| `00` | 保留字段。 |
| `71` | 累加和校验，取低 8 位。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat bionet-biovision.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd bionet-biovision.bin
```
