# Comen Medicus 系列监护仪通讯协议

- 协议标识：comen-medicus
- 品牌：Comen（科曼）
- 覆盖型号：Medicus M、Medicus Delta、COMEN CX-1、C70
- 接口：RS-232 / RS-485
- 通讯参数：115200, 8N1（部分机型 9600）
- 报文长度：10 字节
- 最后更新：2026-08-05

## 说明

Comen 采用以 0xAA 开头的二进制帧，长度字段之后是类型码与负载，尾部为 CRC16。帧头固定便于流式解析，配合 CRC 可以有效识别因干扰产生的错误帧。

## 字节流

AA 01 05 48 52 3D 37 32 91 7D

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `AA` | 帧头 0xAA。 |
| `01` | 类型码 0x01。 |
| `05` | 负载长度 5 字节。 |
| `48 52 3D` | 负载中的 ASCII 片段 "HR="。 |
| `37 32` | ASCII 数值 72，即心率 72 bpm。 |
| `91 7D` | CRC16 校验值，小端序。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat comen-medicus.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd comen-medicus.bin
```
