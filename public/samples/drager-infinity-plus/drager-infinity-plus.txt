# Dräger Infinity 系列监护仪通讯协议

- 协议标识：drager-infinity-plus
- 品牌：Dräger
- 覆盖型号：Infinity Plus、Infinity Delta、Infinity、Infinity VF500
- 接口：RS-232 / RS-422 / HSMS（以太网）
- 通讯参数：9600 / 19200 / 38400, 8N1
- 报文长度：14 字节
- 最后更新：2026-10-30

## 说明

Infinity 系列同时支持 NMEA 风格的文本输出与专有的二进制帧。文本输出以「$」开头、以「*校验」结尾，字段之间用逗号分隔，是三种协议中对人工排障最友好的一种。

## 字节流

24 50 57 45 52 2C 30 2C 31 2A 31 31 0D 0A

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `24` | 起始符 $ 0x24。 |
| `50 57 45 52` | 语句标识 PWER，对应电源与状态类语句。 |
| `2C` | 字段分隔逗号。 |
| `30` | 字段 1，电源状态 0。 |
| `2C` | 字段分隔逗号。 |
| `31` | 字段 2，运行状态 1。 |
| `2A` | 星号 0x2A，其后为校验和。 |
| `31 31` | 校验和 0x11，为 $ 与 * 之间所有字符的异或。 |
| `0D 0A` | 回车换行，语句结束。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat drager-infinity-plus.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd drager-infinity-plus.bin
```
