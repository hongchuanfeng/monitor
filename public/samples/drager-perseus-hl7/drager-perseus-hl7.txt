# 麻醉机 HL7 v2 通用对接说明

- 协议标识：drager-perseus-hl7
- 品牌：Dräger
- 覆盖型号：Perseus A500、Aestiva 5、WATO EX-65、Primus、Servona
- 接口：HL7 v2.3 / v2.5 over TCP
- 通讯参数：TCP（默认端口 2575）
- 报文长度：100 字节
- 最后更新：2026-11-26

## 说明

多品牌麻醉机可通过 HL7 v2 输出结构化的手术室数据，典型消息为 ORU^R01 与 OBX 观察结果的组合。掌握 HL7 结构意味着同一套对接代码可以覆盖多家厂商。

## 报文原文

本协议为文本协议，报文本身就是可读的字符序列，无需按十六进制解读：

```hl7
MSH|^~\&|MIDDLEWARE|CENTRAL|||20261126120000||ORU^R01|1|P|2.5
OBX|1|NM|HR^Heart Rate||60|bpm|||||F
```

段与段之间以回车 0x0D 分隔，消息以 0x1C 结束，两者在下面的片段表里分别标为 ␍ 与 FS。

## 逐段解读

| 片段 | 含义 |
| --- | --- |
| `MSH|` | 段标识 MSH，其后紧跟字段分隔符竖线 0x7C。 |
| `^~\&|` | MSH-2 编码字符集 ^~\&，表示 UTF-8（Unicode 2.2）。 |
| `MIDDLEWARE|` | MSH-3 发送方应用 MIDDLEWARE，标识数据来自中间件。 |
| `CENTRAL|` | MSH-4 发送方设施 CENTRAL，标识本条消息发往的目标系统。 |
| `|` | MSH-5，留空。 |
| `|` | MSH-6，留空。 |
| `20261126120000|` | MSH-7 消息时间 20261126120000。 |
| `|` | MSH-8，留空。 |
| `ORU^R01|` | MSH-9 消息类型 ORU^R01。 |
| `1|` | MSH-10 控制编号 1。 |
| `P|` | MSH-11 处理标识 P。 |
| `2.5` | MSH-12 版本号 2.5。 |
| `␍` | 回车 0x0D，MSH 段结束。 |
| `OBX|` | 段标识 OBX。 |
| `1|` | OBX-1 序号 1。 |
| `NM|` | OBX-2 值类型 NM 表示数值。 |
| `HR^Heart Rate|` | OBX-3 观察标识 HR^Heart Rate。 |
| `|` | OBX-4，留空。 |
| `60|` | OBX-5 观察值 60。 |
| `bpm|` | OBX-6 单位 bpm。 |
| `|` | OBX-7，留空。 |
| `|` | OBX-8，留空。 |
| `|` | OBX-9，留空。 |
| `|` | OBX-10，留空。 |
| `F` | OBX-11 观察结果状态 F，表示最终结果。 |
| `␍` | 回车 0x0D，OBX 段结束。 |
| `1C` | 消息结束符 0x1C，部分设备会省略，采集端需兼容。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat drager-perseus-hl7.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd drager-perseus-hl7.bin
```

也可以直接取用报文原文：`drager-perseus-hl7.txt.raw` 就是这条报文的字符串形式，段之间以回车分隔，可直接贴进调试工具或代码里的样例数据。
