# GE Healthcare CARESCAPE 监护仪串口通讯协议

- 协议标识：ge-carescape-b650
- 品牌：GE Healthcare
- 覆盖型号：CARESCAPE B650、CARESCAPE B850、CARESCAPE CS620、CARESCAPE B650 Pro、MAC 5500 HD
- 接口：RS-232 / RS-422 / HL7 v2 / Ethernet
- 通讯参数：19200, 8N1（默认）；部分机型支持 115200
- 报文长度：16 字节
- 最后更新：2026-11-09

## 说明

CARESCAPE 系列在串口上采用以关键字开头的文本协议，每条记录形如「关键字:值」并以回车符结束。结构简单、便于人工排障，但字段含义随关键字变化，解析前必须建立完整的关键字字典。

## 字节流

45 43 47 52 3A 37 32 0D 53 50 4F 32 3A 39 38 0D

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `45 43 47 52` | 关键字 ECGR，对应 ECG 相关记录。 |
| `3A` | 分隔符冒号 0x3A。 |
| `37 32` | 值为 ASCII "72"，表示心率 72 bpm。 |
| `0D` | 回车 0x0D，本条记录结束。 |
| `53 50 4F 32` | 关键字 SPO2，对应血氧饱和度记录。 |
| `3A` | 分隔符冒号。 |
| `39 38` | 值为 ASCII "98"，表示血氧 98 %。 |
| `0D` | 回车 0x0D，记录结束。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat ge-carescape-b650.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd ge-carescape-b650.bin
```

> 本样本由协议页的示例报文生成，用于联调前的自检。正式接入请以对应型号的原厂通讯协议手册为准。
