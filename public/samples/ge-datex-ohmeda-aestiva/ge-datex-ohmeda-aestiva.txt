# GE Datex-Ohmeda Aestiva 麻醉机通讯协议

- 协议标识：ge-datex-ohmeda-aestiva
- 品牌：GE Healthcare
- 覆盖型号：Aestiva 5、Aestiva CS5、Aestiva 5 iTec、Datex-Ohmeda AS/3、Carestation 620
- 接口：RS-232 / 以太网
- 通讯参数：19200, 8N1
- 报文长度：20 字节
- 最后更新：2026-11-14

## 说明

Aestiva 系列通过串口输出 CSV 风格的文本记录，每行以固定关键字开头，数值以逗号分隔。字段顺序固定，便于用电子表格或脚本做快速验证。

## 字节流

56 45 4E 54 4D 4F 44 45 3A 50 43 56 0D 56 54 3A
35 30 30 0D

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `56 45 4E 54 4D 4F 44 45` | 关键字 VENTMODE，对应通气模式记录。 |
| `3A` | 冒号分隔符。 |
| `50 43 56` | 值为 ASCII "PCV"，表示压力控制通气。 |
| `0D` | 回车，本行结束。 |
| `56 54` | 下一行关键字 VT，对应潮气量。 |
| `3A` | 冒号分隔符。 |
| `35 30 30` | 值为 ASCII "500"，对应潮气量 500 mL。 |
| `0D` | 回车，记录结束。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat ge-datex-ohmeda-aestiva.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd ge-datex-ohmeda-aestiva.bin
```
