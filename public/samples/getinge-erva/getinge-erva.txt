# Getinge ERVA / Servona 手术室数据接口协议

- 协议标识：getinge-erva
- 品牌：Getinge
- 覆盖型号：Getinge ERVA、Getinge Servona、Getinge Target 3、Getinge Amsco
- 接口：RS-232 / 以太网
- 通讯参数：9600, 8N1
- 报文长度：16 字节
- 最后更新：2026-08-18

## 说明

Getinge 的手术室接口以「GRP0」开头的分组文本组织数据，每个分组以 END 结束。分组内字段以逗号分隔，整体结构接近 HL7 分段的扁平化表达。

## 字节流

47 52 50 30 56 45 4E 54 3A 50 43 56 0D 45 4E 44

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `47 52 50 30` | 分组标签 GRP0，标识后续数据为一个数据组。 |
| `56 45 4E 54` | 组内首个字段关键字 VENT。 |
| `3A` | 冒号分隔符。 |
| `50 43 56` | 字段值 PCV，表示压力控制通气。 |
| `0D` | 回车，字段行结束。 |
| `45 4E 44` | 分组结束标记 END。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat getinge-erva.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd getinge-erva.bin
```
