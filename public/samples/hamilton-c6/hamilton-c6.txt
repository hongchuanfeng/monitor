# Hamilton Medical C6/C7 呼吸机通讯协议

- 协议标识：hamilton-c6
- 品牌：Hamilton Medical
- 覆盖型号：Hamilton C6、Hamilton C7、Hamilton C1、Hamilton T1
- 接口：RS-232 / RS-485 / 以太网（Hamilton RS/232 协议）
- 通讯参数：9600 / 19200, 8N1
- 报文长度：16 字节
- 最后更新：2026-10-06

## 说明

Hamilton RS/232 协议采用 0x02 起始、0x03 结束的二进制帧，帧内含长度、命令标识与数据区，末尾为累加校验。命令标识区分实时监视、参数设置与报警读取。

## 字节流

02 00 0B 00 33 01 3C 00 0A 00 1F 00 1E 00 C2 03

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `02` | 帧起始 0x02。 |
| `00 0B` | 数据区长度 11 字节。 |
| `00 33` | 命令标识 0x3300，实时监视类命令。 |
| `01` | 数据区子类型 0x01，表示参数上报。 |
| `3C 00` | 参数标识 0x003C，小端序，对应潮气量 Vte。 |
| `0A 00` | 参数值 10 mL。 |
| `1F 00` | 参数标识 0x001F，小端序，对应总呼吸频率 fTotal。 |
| `1E 00` | 参数值 30 bpm。 |
| `C2` | 累加校验值。 |
| `03` | 帧结束 0x03。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat hamilton-c6.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd hamilton-c6.bin
```
