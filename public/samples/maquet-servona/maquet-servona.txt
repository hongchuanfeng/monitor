- 覆盖型号：Servona、Servona C、Primus、Primus 100、MICARDIS

## 说明

MAQUET 的串口接口采用「命令 — 应答」式的文本协议，双方均以关键字开头的文本行交互，并以回车结束。请求与响应成对出现，便于做同步事务。

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `56 45 4E 54` | 关键字 VENT，对应通气参数记录。 |
| `20` | 空格分隔。 |
| `50 43 56` | 文本字段 PCV，表示压力控制通气。 |
| `0D` | 回车，本行结束。 |
| `46 52 45 51` | 下一行关键字 FREQ，对应频率记录。 |
| `20` | 空格分隔。 |
| `30 38` | 数值 08，对应呼吸频率 8 bpm。 |
| `0D` | 回车，记录结束。 |
