# Masimo Radical-7 脉搏血氧仪通讯协议

- 协议标识：masimo-radical7
- 品牌：Masimo
- 覆盖型号：Radical-7、Radical-7+、MightySat、Radical-7 with NIBP
- 接口：RS-232 / USB（充电底座）
- 通讯参数：9600 / 115200, 8N1
- 报文长度：8 字节
- 最后更新：2026-10-12

## 说明

Radical-7 通过串口输出血氧参数与脉搏波。其中 perfused index（灌流指数）是 Masimo 特有的派生参数，用于评估外周灌注状况，在低灌注场景下比单纯血氧饱和度更有临床参考价值。

## 字节流

4D 53 01 01 12 00 5A 56

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `4D 53` | 帧头 MS（ASCII 0x4D 0x53）。 |
| `01` | 块类型 0x01，代表测量数据块。 |
| `01` | 本块包含 1 个参数。 |
| `12` | 参数 ID 0x12，指明后续数值采用双字节无符号编码。 |
| `00 5A` | 参数值 0x005A，即 90，表示血氧饱和度 90 %。 |
| `56` | 异或校验值，覆盖帧头至最后一个数值字节。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat masimo-radical7.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd masimo-radical7.bin
```
