# 迈瑞 BeneHeart D6 十二导联心电分析接口

- 协议标识：mindray-beneheart-d6
- 品牌：Mindray（迈瑞）
- 覆盖型号：BeneHeart D6、BeneHeart D3、BeneHeart P1
- 接口：RS-232 / 以太网
- 通讯参数：115200, 8N1（串口导出）
- 报文长度：15 字节
- 最后更新：2026-11-05

## 说明

BeneHeart D6 可作为独立的十二导联心电图机工作，也可在监护模式下通过专用接口导出心电分析结论。该接口以 0x7E 定界，负载中携带各导联测量结果与自动诊断结论。

## 字节流

7E 0A 00 21 01 01 40 01 96 00 8C 00 E2 CE 7E

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `7E` | 起始符 0x7E。 |
| `0A` | 数据区长度 10 字节。 |
| `00` | 控制字段 0x00。 |
| `21` | 命令码 0x21，对应心电测量结果。 |
| `01` | 导联组编号 1。 |
| `01` | 导联序号 1。 |
| `40 01` | PR 间期 0x0140，小端序，即 320 ms。 |
| `96 00` | QRS 时限 0x0096，即 150 ms。 |
| `8C 00` | QT 间期 0x008C，即 140 ms。 |
| `E2 CE` | CRC16 校验值，小端序。 |
| `7E` | 结束符 0x7E。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat mindray-beneheart-d6.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd mindray-beneheart-d6.bin
```
