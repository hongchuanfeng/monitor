# 迈瑞 BeneVision N 系列监护仪通讯协议

- 协议标识：mindray-benevision-n22
- 品牌：Mindray（迈瑞）
- 覆盖型号：BeneVision N17、BeneVision N22、BeneVision N27、BeneVision N19、BeneHeart D6
- 接口：HL7 v2.3 / v2.5 over TCP / RS-422 / RS-485 / 以太网（NetComm）
- 通讯参数：TCP（默认端口 2575）；串口 115200, 8N1
- 报文长度：337 字节
- 最后更新：2026-11-27

## 说明

BeneVision N 系列通过 HL7 v2 输出生理参数，以 ORU^R01 消息承载，测量值落在 OBX 段并采用 LOINC 编码标识。同一套消息结构既走以太网通道，也可在网关上转成串口输出。

## 报文原文

本协议为文本协议，报文本身就是可读的字符序列，无需按十六进制解读：

```hl7
MSH|^~\&|MINDRAY|BENEVISION N22|MEDCOLLECTOR||20261126120000||ORU^R01|1|P|2.5
PID|1||P000098^^^HOSPITAL||MRN2026112601^^^HOSPITAL||19850612|M
OBR|1|ORD2026112601|P000098|HR^Heart Rate^LN||||20261126120000
OBX|1|NM|8867-4^Heart rate^LN||72|bpm|||||F
OBX|2|NM|2708-6^SpO2^LN||98|%|||||F
OBX|3|NM|9279-1^Respiratory rate^LN||16|/min|||||F
```

段与段之间以回车 0x0D 分隔，消息以 0x1C 结束，两者在下面的片段表里分别标为 ␍ 与 FS。

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat mindray-benevision-n22.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd mindray-benevision-n22.bin
```

也可以直接取用报文原文：`mindray-benevision-n22.txt.raw` 就是这条报文的字符串形式，段之间以回车分隔，可直接贴进调试工具或代码里的样例数据。
