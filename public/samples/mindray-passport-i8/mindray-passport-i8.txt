# 迈瑞 Passport i8 急救监护仪通讯协议

- 协议标识：mindray-passport-i8
- 品牌：Mindray（迈瑞）
- 覆盖型号：Passport i8、iPM8、iPM12
- 接口：RS-232 / 以太网
- 通讯参数：115200, 8N1
- 报文长度：11 字节
- 最后更新：2026-11-12

## 说明

Passport i8 面向院前急救与转运场景，协议沿用迈瑞统一的 0x7E 定界帧结构。相比床旁系列，该设备更强调会话建立与会话状态查询。

## 字节流

7E 06 01 11 01 00 64 00 D4 FB 7E

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `7E` | 起始符 0x7E。 |
| `06` | 数据区长度 6 字节。 |
| `01` | 控制字段 0x01。 |
| `11` | 命令码 0x11，对应参数订阅。 |
| `01 00` | 参数编号 0x0001，小端序，对应心率测量项。 |
| `64 00` | 参数原始值 0x0064，小端序，即 100 bpm。 |
| `D4 FB` | CRC16 校验值，小端序。 |
| `7E` | 结束符 0x7E。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat mindray-passport-i8.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd mindray-passport-i8.bin
```
