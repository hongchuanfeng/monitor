- 协议标识：mindray-wato-ex65
- 品牌：Mindray（迈瑞）
- 覆盖型号：WATO EX-65、WATO EX-65 Pro、WATO EX-100、WATO EX-120
- 接口：RS-232 / 以太网（NetComm）

## 说明

WATO EX 系列沿用迈瑞统一的 0x7E 定界帧格式，命令码区分呼吸参数上报、麻醉气体上报、通气控制与系统状态查询，负载中参数编号与数值成对出现。

## 字节流

7E 0F 00 21 03 01 00 F4 01 00 08 1E 00 00 1A 0A
00 24 4C 7E

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `7E` | 起始符 0x7E。 |
| `0F` | 数据区长度 15 字节。 |
| `00` | 控制字段 0x00，请求方向。 |
| `21` | 命令码 0x21，通气参数上报。 |
| `03` | 参数个数 3。 |
| `01 00` | 参数编号 0x0001，小端序，对应潮气量 VT。 |
| `F4 01` | 参数值 500 mL。 |
| `00 08` | 参数编号 0x0800，小端序，对应呼吸频率 RR。 |
| `1E 00` | 参数值 30 bpm。 |
| `00 1A` | 参数编号 0x1A00，小端序，对应气道峰压 Ppeak。 |
| `0A 00` | 参数值 10 cmH₂O。 |
| `24 4C` | CRC16 校验值，小端序。 |
| `7E` | 结束符 0x7E。 |
