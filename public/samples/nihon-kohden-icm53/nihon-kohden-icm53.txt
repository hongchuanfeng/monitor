# Nihon Kohden iCM 中央站接口协议

- 协议标识：nihon-kohden-icm53
- 品牌：Nihon Kohden（日本光電）
- 覆盖型号：iCM-53、iCM-5432、LifeScope TR、CNS-6200、VitalSign
- 接口：RS-232 / 以太网（NetBoss）
- 通讯参数：9600 / 19200, 8N1
- 报文长度：14 字节
- 最后更新：2026-09-28

## 说明

iCM 系列中央站接口采用空白分隔的定长文本记录，记录类型由开头两个字符标识，数值字段按固定列宽排列。结构极为朴素，但对列位置与记录类型匹配的正确性要求很高。

## 字节流

53 30 32 20 30 39 38 20 31 30 30 20 2D 0D

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `53 30 32` | 记录类型 S02，对应一类监护测量记录。 |
| `20` | 字段分隔空格。 |
| `30 39 38` | 数值字段 098。 |
| `20` | 字段分隔空格。 |
| `31 30 30` | 数值字段 100。 |
| `20` | 字段分隔空格。 |
| `2D` | 短横线，标记该字段当前无有效值。 |
| `0D` | 回车 0x0D，记录结束。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat nihon-kohden-icm53.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd nihon-kohden-icm53.bin
```
