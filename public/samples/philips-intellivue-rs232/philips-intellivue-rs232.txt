# Philips IntelliVue 监护仪 RS-232 通讯协议

- 协议标识：philips-intellivue-rs232
- 品牌：Philips
- 覆盖型号：IntelliVue MP20/MP30、IntelliVue MX450、IntelliVue MX500、IntelliVue MX750、IntelliVue Efficia CM120、IntelliVue Efficia CM220
- 接口：RS-232 / RS-422（多床位） / HL7 v2 / Ethernet
- 通讯参数：115200, 8N1（部分型号支持 19200/38400）
- 报文长度：16 字节
- 最后更新：2026-11-18

## 说明

IntelliVue 系列通过一种基于 STX/ETX 定界的二进制帧格式传出实时参数与波形。帧头、帧类型、序号与长度字段共同定位数据负载，末字节为按位累加校验。波形以差分编码方式压缩传输，需按通道换算表还原原始采样点。

## 字节流

0B 02 00 1F 00 08 00 03 00 5A 00 04 00 62 EC 0D

## 逐段解读

| 字节 | 含义 |
| --- | --- |
| `0B` | STX，帧开始，固定 0x0B。 |
| `02` | 帧类型 0x02，代表实时测量数据帧。 |
| `00 1F` | 序号 31，上位机应答时需原样回填该值。 |
| `00 08` | 负载长度 8 字节，随后应读取 8 字节内容。 |
| `00 03` | 参数 ID 0x0003，对应心率测量项。 |
| `00 5A` | 心率原始值 0x005A，即 90 bpm。 |
| `00 04` | 参数 ID 0x0004，对应血氧饱和度。 |
| `00 62` | 血氧原始值 0x0062，即 98 %。 |
| `EC` | 校验和，帧类型至负载区末字节的累加和低 8 位。 |
| `0D` | ETX，帧结束，固定 0x0D。 |

## 使用方式

```bash
# 直接把原始字节写入串口或 TCP 连接
cat philips-intellivue-rs232.bin > /dev/ttyUSB0

# 或者查看十六进制内容
xxd philips-intellivue-rs232.bin
```
